# Spill (VG1 Card Game Project)

A turn-based browser card game project made in **VG1**.  
The game includes a menu system, deck page, shop, tutorial and a combat screen.

This was built as a school project to practice **HTML, CSS and JavaScript** and learn how to structure a bigger project with multiple pages and game logic.

---

## 🎮 Features

- **Main Menu UI**
- **Combat Screen** (turn-based combat)
- **Deck page** (view/manage your deck)
- **Shop page**
- **Tutorial page**
- **Settings page**
- Background music + images/assets

---

## 🛠 Tech Stack

- **HTML**
- **CSS**
- **JavaScript (Vanilla)**
- (Optional/extra) SQL file in `database/script.sql`

---

## ▶️ How to Run

### Option 1 — Run locally in browser (recommended)
1. Download/clone the project
2. Open this file in your browser:

html/menu.html

yaml
Copy code

From the menu you can navigate to the other parts of the game.

---

### Option 2 — Run with VS Code Live Server
1. Open the project folder in VS Code
2. Install the extension: **Live Server**
3. Right-click `html/menu.html` → **Open with Live Server**

This is useful because some browsers block media/scripts when opening files directly.
